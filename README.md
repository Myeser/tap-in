# tap in 🔥

NFC tap page: shows a rainbow page with cats, a goblin and a McDonald's dog, with buttons to [Instagram](https://instagram.com/myeserole) and [SoundCloud](https://soundcloud.com/detonate-dead).

- `index.html` – the page
- `assets/` – processed images used by the page (backgrounds removed, resized)
- `sources/` – original downloaded images
